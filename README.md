# Sri Damodar Aarti 3D

An interactive 3D Aarti darshan web application for Sri Sri Radha Damodar / Yashoda Damodar during the sacred month of Kartik.

## Features
- **Interactive 3D Diya Aarti**: Move the ghee lamp in circular motions around the Lord (lotus feet, waist, head, full body).
- **Synchronized Damodarashtakam Bhajan**: Full 8 verses synchronized with lead & chorus audio.
- **Full Lyrics Modal**: Click the 3-dot button (`⋮`) to view all 8 Sanskrit verses and English translations with real-time active verse highlighting and auto-scroll.
- **Silent Double-Click Toggle**: Silently switch between Aarti mode and 3D rotation view once Aarti is complete.
- **Falling Flower Petals**: Peaceful floral rain offering upon Aarti completion.

## Deployment
Configured for instant zero-config deployment on Vercel.
